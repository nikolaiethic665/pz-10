[Демонстрация](https://nikolaiethic665.github.io/pz-10/) · [Исходный код](https://github.com/nikolaiethic665/pz-10/tree/kolodei) · [Отчёт PDF](https://nikolaiethic665.github.io/pz-10/materials/report.pdf) · [Pull Request](https://github.com/nikolaiethic665/pz-10/pull/1)

## Цель

Освоить семантическую разметку таблиц.

## Задание

Создать таблицу с заголовками и читаемой структурой.

## Реализация

Таблица содержит подпись и раздельные шапку, тело и итог. Заголовки дней и времени получили scope. Ячейка обслуживания занимает два временных столбца. Итог показывает четыре свободных окна. CSS добавляет границы и перебивку строк.
